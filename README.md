## Engineering principles

- **Clear boundaries:** typed interfaces and controlled execution over hidden side effects.
- **Verification:** regression tests and repeatable checks throughout implementation.
- **Evidence:** claims backed by releases, test results, or observable behaviour.
- **Iteration:** ship useful work, respond to review, improve the implementation.
