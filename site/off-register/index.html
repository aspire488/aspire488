about me, briefly

I'm Joel, a student engineer. I learn by building things, shipping them, and finding out why they break, then I write down what is actually true about them: what shipped, what is tested, and what has only run on one PC.

Campus Bus started as my OOP course project and ended up with a seat map, route lines and a bus pass the brief never asked for. Lately it's agent tooling: KIO, a companion runtime I'm rebuilding one gate at a time; UEA, which hands proof work to tree-sitter and Z3; and fixes in other people's AI evaluation and red-teaming tools.

Ship small. Learn fast. Make the system prove it.
