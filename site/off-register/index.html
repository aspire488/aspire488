about me, briefly

Campus Bus started as my OOP course project. It ended up with a seat map, route lines and a bus pass the brief never asked for.

That is how most of it goes: I build the thing, then I write down what is actually true about it: what shipped, what is tested, and what has only run on one PC. Lately it's agent tooling: KIO, a companion runtime I'm rebuilding one gate at a time; UEA, which hands proof work to tree-sitter and Z3; and fixes in other people's AI evaluation and red-teaming tools.
